## 🚀 How to View the Portfolio

### Option 1: Open Directly
Double-click `index.html` in your file explorer, or right-click and choose **Open with Google Chrome / Microsoft Edge / Brave / Firefox**.

### Option 2: Local Python Server
Run the following in PowerShell:
```powershell
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

---

## 🌐 Quick Deployment (GitHub Pages)

1. Create a repository on GitHub (e.g., `portfolio`).
2. Push `index.html`, `styles.css`, `script.js`, and `README.md`.
3. Go to **Repository Settings > Pages** -> set source to branch `main` and folder `/ (root)`.
4. Your website will be live in 1 minute at `https://<your-username>.github.io/<repo-name>`!
